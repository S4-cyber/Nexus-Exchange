# Unified Scout lead memory

Automatically retain successful SAM, TED, UK FTS and CanadaBuys search results in a separate local SQLite database (scout-leads.sqlite3 in the existing user data directory). This is a historical source observation store, not an active opportunity index or the compiled OCDS archive. The latter remains unchanged. Use Scout lead history to filter by source/title/reference, open fixed official links and export a bounded historical report. Latest retrieval per source-scoped canonical identity is shown, not cross-source entity resolution.

Adapts the existing OpportunityArchive's bounded transactions, canonical payload checks, exact replay handling and fail-closed conflict semantics. Same-time conflicting observations reject the entire batch. Retain at most 10,000 observations, 75 per search and 100 displayed records. No silent eviction. Save only an allowlisted projection, source identity, title, reported dates, reason codes, and batch page digests, not raw documents, contacts, API keys, query parameters or asserted transaction authority. SHA-256 checks detect accidental corruption, not malicious local database modification or independently authenticated evidence. Data is plaintext trusted local storage, not an encrypted profile vault or tenant-isolated production DB.

Every saved observation is historical: no automatic research eligibility from prior results, unknown cash exposure, no transaction authority. Re-evaluate staleness, reported deadlines and later known UK release events at display time; generate evidence tasks. UK process history remains incomplete and no OCDS merge is attempted. Cross-source dedup, source disappearance, full notice supersession, authentic evidence and durable per-task state are pending. A successful search does not mean revenue. In-flight local writes may commit during a concurrent halt; task and lead stores are separate transactions, so crash reconciliation remains a separate gate.

No additional dependencies, accounts, paid services or live requests during development. Tests integrate mock reports from the actual four adapters, local replay/rollback, integrity checks, historical screening and desktop task logging. No new commercial dispatch.
