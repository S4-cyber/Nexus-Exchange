# Coordinated free-first engineering protocol

Owner-authorized development policy 2026-11-25. This document is specific to Nexus Exchange. Nexus Operative retains its own independent roadmap, risk controls, versioning, sprint and AGENTS.md. Neither project gains runtime commercial or trading permissions.

## Executable workspaces

Use the existing authorized repository-specific Codex Cloud environment, Codespace, or local worktree only when actually accessible and confirmed within included/free allowances. A browser workspace URL is not terminal access; do not disclose session links. Before work, inspect status, branch, exact remote commit, roadmap, existing PRs and active CI. Start an isolated worktree from the selected verified candidate. Use private local test data and owned fixtures; never share credentials, production data or logged-in profiles. Run the commands in AGENTS.md and existing CI; the GUI needs a display and the frozen Windows executable needs native verification. Preserve exact base/head and avoid competing writes. Report any unavailable execution environment; do not claim tests from an unrun workspace.

Switch to legitimate free/open-source alternatives when quotas or paywalls are encountered. No billing or authentication circumvention, account creation to evade quotas, ambiguous credit consumption, paid provisioning, or unapproved external data sharing. Review exact upstream revisions, licenses, dependencies, security, maintenance, telemetry, privacy and cost; use owned fixtures and benchmarks before adoption. No wholesale dependency or prompt imports. Do not treat no security scan/findings as a clean audit.
