# Capability-driven public opportunity discovery

The dashboard's Capability search planner creates a deterministic local plan
for one of four actually implemented Operator services. Only explicitly
selected owner-profile sources are considered. The narrow service phrases
are fixed, not inferred buyer demand. SAM has separate solicitation and
combined-synopsis options; CanadaBuys applies the phrase locally to the daily
dataset. TED and Contracts Finder require declared CPV prefixes, never
inferred classifications. Find a Tender is a broad 24-hour release query.
USAspending remains historical contractor intelligence, not an open
opportunity adapter. Unselected sources and unsupported catalog sources
are not included. Zero declared availability holds otherwise runnable rows.

Each option displays its real provider filter, date window, request count
ceiling and response-byte ceiling. Plan digest includes the profile
revision, current capability catalogue and all options. At most 69 options;
5-minute plan lifetime, one selected search and separate explicit consent.
Reconstruct the exact plan before dispatch, re-read current profile inside
the existing single worker, deny changed/expired plan or halt. SAM key is
entered in a masked dialog and passed ephemerally to the existing adapter;
not included in plans, persisted reports or journal targets. No arbitrary
URLs, new transport, automatic batches or provider credentials stored.
Existing provider-specific consent, bounds, parsing, archive and contrary
evidence handling remain unchanged. Full returned provider reports reach
the existing lead archive; Matrix can then apply local capability hints.
The profile check is cooperative and cannot authenticate facts or prevent
all concurrent file edits. Manual review remains necessary; a narrow
title phrase or broad classification can miss relevant work. No verified
live pilot, legal eligibility, revenue, commercial dispatch or paid service.
Eight regression tests and native owned GUI smoke; exact-head hosted CI
required. No changes to Nexus Operative or formal main gate acceptance.
